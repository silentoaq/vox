Vox 開始下載了

沒有開始？重新下載 macOS 13 以上，Apple 晶片（M1 以後） Windows 版

Vox 沒有經過 Apple 公證，第一次打開時 macOS 會擋下來。照下面的順序做一次，之後就能直接打開。

  1. 1

    把 Vox 拖進「應用程式」

    1. 打開剛下載的 Vox.dmg
    2. 把 Vox 的圖示拖到旁邊的「應用程式」資料夾

    不放進「應用程式」也能用，但不會自動更新。

  2. 2

    第一次打開，macOS 說無法確認 Vox

    1. 在跳出的視窗按 完成
    2. 打開 系統設定，按左邊的 隱私權與安全性
    3. 往下捲到「安全性」，在說 Vox 被阻擋的那一行按 仍要打開
    4. 輸入電腦的密碼，再按一次 仍要打開
  3. 3

    Vox 打開了

    登入 YouTube Music 或 Spotify 就能開始點歌。

    看使用說明

只從 vox.lichitdev.com 或 GitHub 的 silentoaq/vox 下載。從別處拿到的 Vox，不要略過這些提醒。
