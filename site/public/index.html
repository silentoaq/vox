Vox 開始下載了

沒有開始？重新下載 Windows 10、11

安裝檔還沒有數位簽章，瀏覽器和 Windows 會跳出提醒。照順序按紅框圈起來的地方就裝好了。

你的瀏覽器

  1. 1

    Edge 右上角顯示「不常下載」

    1. 滑鼠移到檔案上，按「…」
    2. 選「保留」
    3. 按「刪除」旁的箭頭
    4. 選「仍要保留」
    5. 按「開啟檔案」

    不要按「刪除」，檔案會被丟掉。

  2. 1

    在 Chrome 打開剛下載的安裝檔

    1. 按網址列右邊的下載圖示
    2. 按「VoxSetup.exe」
  3. 2

    如果跳出藍色的「Windows 已保護您的電腦」

  4. 3

    跳出 Vox 安裝程式

  5. 4

    Vox 打開了

    登入 YouTube Music 或 Spotify 就能開始點歌。

    看使用說明
!

Windows 11 擋下 Vox，沒有「仍要執行」

這是「智慧型應用程式控制」，要先關閉。Windows 10 不會遇到。

舊版 Windows 11 關閉後開不回來，要重設 Windows 才會恢復。

只從 vox.lichitdev.com 或 GitHub 的 silentoaq/vox 下載。從別處拿到的安裝檔，不要略過這些提醒。
